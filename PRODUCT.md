# OnlineStore

## Platform
Web, local university demonstration on Windows, backed by the existing ASP.NET Core API and SQL Server.

## Users and purpose
Shoppers browse the real product catalog, maintain a browser cart and place orders for an existing customer. The student demonstrates product/category/customer administration and order lifecycle.

## Confirmed constraints
HTML5, CSS3 and Vanilla JavaScript ES modules; ASP.NET static files; no frontend framework, payment processing, new database or public deployment. Preserve API contracts and business rules. GEL is the primary display currency. Admin has no authentication and is explicitly a demo interface. GitHub publication is deferred by the user.

## Visual reference
FinalProject.pdf pages 1–2: light catalog, dark navigation, product imagery, category filtering, administrative tables. Georgian interface; no copied third-party branding. Product images are labeled local illustrative placeholders because the API has no image field.
